Entry for the make.fun bounty [Sum up 23 November's world news in one image](https://make.fun/bounty/news-image-20261123).

`main.py` (Python 3.13, standard library only, no network) copies `entry.png` to `/output/entry.png`: a front page of 39 stories reported on Monday 23 November 2026, led by NATO's emergency meeting over Russian missiles in Poland, with a stat strip, region bar, pinned map and date-check footer.

`build_image.py` draws the image with Pillow from headlines of that day.
